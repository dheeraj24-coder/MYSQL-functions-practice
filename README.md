# MySQL Functions & Constraints Practice

## 📌 Project Overview

This repository contains my **MySQL practice queries** covering important SQL concepts such as **table creation, data insertion, date functions, string functions, mathematical functions, aggregate functions, JSON functions, constraints, and foreign keys**.

The main objective of this practice is to strengthen my understanding of **MySQL syntax and commonly used SQL functions** through practical examples.

## 🚀 How to Run

1. Install **MySQL** or use a MySQL-compatible environment such as MySQL Workbench.
2. Open the SQL file from this repository.
3. Connect to your MySQL database.
4. Run the queries sequentially.
5. Use `SELECT` statements to view the results.

> **Note:** Run the `Hospital` table creation query before creating the `Doctor` table because the `Doctor` table contains a foreign key referencing `Hospital`.
